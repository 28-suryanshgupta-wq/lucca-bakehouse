LUCCA BAKEHOUSE RECIPE HUB

FREE WEBSITE PROTOTYPE
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge or Firefox.
3. Search a menu item, select a category, open a recipe.
4. Change Servings to scale ingredient quantities.

To publish for free:
- Create a free GitHub account.
- Create a public repository and upload index.html and recipes.json.
- In repository Settings > Pages, select Deploy from a branch, choose main and /root, then Save.
- GitHub Pages will provide a public website URL.

IMPORTANT RECIPE NOTE:
The recipe manual is a recreated recipe set based on menu descriptions, not verified original Lucca Bakehouse formulations. Quantities, methods, allergens and food-safety instructions must be checked and approved by Lucca's authorised manager before use. The website is a static prototype and does not include logins, database storage or a connected AI model.
